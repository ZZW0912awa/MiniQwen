# 二进制语料报告

- 语料：`data/processed/corpus.txt`（5,232,101 字 / 15,484,681 字节）
- 分词器：`tokenizer.json`（词表 16,384）
- 存储类型：`uint16`，每个 token 2 字节
- 耗时：6.4 秒（含全量解码往返校验）

## 产出

| 文件 | token 数 | 大小 | 说明 |
|---|---:|---:|---|
| `train.bin` | 2,811,858 | 5.36 MB | 训练集（97.98%） |
| `val.bin` | 58,079 | 0.11 MB | 验证集（2.02%） |
| `meta.json` | — | — | 元信息与 sha256 |

合计 **2,869,937** 个 token。

## 切分

切分点在第 **5,129,866** 个字符（全篇 98.05%），对齐到**章节边界**而不是硬切。

> 为什么要对齐到章节边界：硬切会把一句话劈成两半，前半截进训练集、后半截进验证集。模型训练时见过前半句，再去验证后半句，**测出来的 loss 会偏乐观**。

## 校验

| 检查 | 结果 |
|---|---|
| 文件大小 == token 数 × 2 | ✅ |
| 最大 id ≤ 65,535 | ✅ |
| train 解码往返一致 | ✅ |
| val 解码往返一致 | ✅ |

## 存法对比

| 存法 | 字节/token | 总大小 |
|---|---:|---:|
| 原始 UTF-8 文本 | — | 14.77 MB |
| **uint16（本方案）** | 2 | **5.47 MB** |
| int32 | 4 | 10.95 MB |
| int64 | 8 | 21.90 MB |
| Python list of int（内存） | ~28 | 77 MB |

## 怎么用

```python
import numpy as np
data = np.memmap('data/processed/train.bin', dtype=np.uint16, mode='r')
# 取任意窗口都是 O(1)，不读整个文件进内存
x = data[i:i+512].astype(np.int64)
```
